# Warbound

Card game multiplayer de povos históricos, como Romanos, Samurais e Vikings.

## Tecnologia definida

- Linguagem: Java 17+
- Interface: JavaFX
- Comunicação distribuída: Java RMI
- Arquitetura: cliente-servidor com estado autoritativo no servidor
